# CodeCoDriver 项目设计

## 1. 项目定位

`CodeCoDriver` 是一个面向软件维护场景的多智能体工程执行系统。它不是一个普通聊天助手，而是一个围绕真实代码仓库运行的 Agent Runtime。

系统目标是接收工程任务并完成以下闭环：

1. 理解任务与仓库背景
2. 规划执行步骤
3. 召回相关代码与历史经验
4. 生成补丁或测试
5. 运行验证
6. 审查风险
7. 沉淀长期记忆

## 2. 目标用户

主要目标用户：

- 个人开发者
- 小团队后端工程师
- 平台工程 / AI 应用工程师
- 需要在既有代码库中快速定位与修改问题的开发者

简历项目视角下，目标不是服务大量真实用户，而是证明你具备以下能力：

- 设计多智能体系统
- 设计工程化运行时
- 处理真实代码仓库上下文
- 管理长期记忆
- 建立可验证、可追踪的执行闭环

## 3. 问题定义

现有代码 Agent 项目常见问题：

- 只会聊天，无法形成受控执行流程
- 依赖单次上下文，缺乏跨任务记忆
- 只能做代码生成，不能做仓库理解与验证
- 缺乏审计与可观测性
- 无法解释为什么改这些文件、为什么失败

`CodeCoDriver` 要解决的问题是：

- 如何在真实仓库中稳定地找到相关上下文
- 如何把任务执行拆成可控的多步工作流
- 如何在失败后重规划而不是直接结束
- 如何把历史任务经验变成后续任务的可复用记忆

## 4. 核心能力

### 4.1 任务执行闭环

系统应支持以下闭环能力：

- 接收自然语言任务、Issue、报错日志
- 生成结构化计划
- 对仓库做多策略检索
- 生成补丁和测试
- 运行测试和静态检查
- 输出风险审查结论
- 将成功和失败经验写入长期记忆

### 4.2 多智能体协作

系统采用受控多智能体协作，而不是自由对话。建议保留以下 5 个主 Agent：

- `Planner Agent`
- `Codebase Agent`
- `Patch Agent`
- `Test Agent`
- `Reviewer Agent`

### 4.3 长期记忆

记忆不是聊天历史，而是仓库与任务经验的持久层。至少包括：

- 仓库记忆
- 任务记忆
- 模式记忆
- 执行记忆

### 4.4 可观测性

系统需要能回答以下问题：

- 任务执行到了哪一步
- 每一步用了哪些上下文
- 调用了哪些工具
- 哪一步失败
- 为什么进行了重规划
- 最终 patch 是否通过验证

## 5. MVP 范围

第一阶段只做最有价值的闭环，不做泛化过度的功能。

### 5.1 支持的输入

- 自然语言任务描述
- Issue 文本
- 报错日志
- 指定仓库路径

### 5.2 支持的任务类型

- `Bug Fix`
- `Test Generation`
- `Code Explanation`

其中主打 `Bug Fix`，`Test Generation` 作为增强能力。

### 5.3 MVP 功能清单

- 导入并索引单个仓库
- 读取文件结构、符号、基础依赖关系
- 提交任务并创建执行流
- 基于计划进行上下文召回
- 生成补丁 diff
- 执行测试
- 输出评审结论
- 查看完整 trace
- 沉淀基础长期记忆

### 5.4 明确不做

为了避免范围失控，第一版不做：

- 自动提交 Git PR
- IDE 深度插件
- 多仓库共享知识网络
- 完整生产级沙箱隔离
- 海量语言支持
- 自由自治的长时间无人监督执行

## 6. 非功能性要求

### 6.1 可控性

- 所有 Agent 只能通过受控运行时执行
- 工具调用必须经过策略检查
- 高风险修改支持人工审批

### 6.2 可追踪性

- 每个步骤都要落库
- 保留输入、输出、工具调用、耗时、状态
- 保留关键 prompt 与结构化结果引用

### 6.3 可替换性

- LLM Provider 可替换
- 检索策略可替换
- 文档处理侧车可替换
- 工具可通过 MCP 或本地接口扩展

### 6.4 可评估性

- 能构造离线任务集
- 能比较不同策略
- 能沉淀成功率、测试通过率、重规划次数等指标

## 7. 成功标准

项目完成后应满足以下最小标准：

1. 能对一个中小型仓库建立索引并执行真实任务
2. 能输出结构化计划、上下文召回结果和补丁
3. 能自动跑测试并根据结果触发重规划
4. 能记录和查询历史任务与执行轨迹
5. 能展示长期记忆在后续任务中的复用
6. 能在演示中清晰展示端到端流程

## 8. 对外包装方式

该项目对外应表述为：

- 一个面向真实代码仓库的软件工程多智能体运行时
- 一个具备长期记忆、验证闭环和可观测性的 Agent 系统
- 一个以 Go 为主、支持 Python 能力侧车和 MCP 工具扩展的混合架构平台
